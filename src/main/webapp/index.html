Gestion UE – Service web RESTful

Le serveur fonctionne. L'API se trouve sous rest/ :

  • GET rest/options – liste des options
  • GET rest/options?domaine=Mathématiques
  • GET rest/options/1
  • GET rest/etudiants – liste des étudiants
  • GET rest/etudiants/I001
  • GET rest/etudiants/option?codeOption=1 (XML)

Les liens ci-dessus ne testent que les requêtes GET. Pour POST / PUT / DELETE, utilisez Postman.
